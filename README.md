# CRUD Management App

A simple and responsive **CRUD (Create, Read, Update, Delete) Management System** built using **HTML, CSS, and JavaScript**.

The project demonstrates the core concepts of managing data dynamically in the browser, including adding, displaying, updating, and deleting records.

## 📸 Preview

![CRUD Management App Preview](./assets/preview.png)

##  Features

-  **Create** — Add new records to the system.
-  **Read** — Display all stored records in a structured table.
-  **Update** — Edit existing records.
-  **Delete** — Remove records from the system.
-  **Search** — Search through existing records.
-  **Responsive Design** — Works across different screen sizes.
-  **Modern UI** — Clean and user-friendly interface.
-  **Dynamic Updates** — Changes are reflected immediately without refreshing the page.

##  Technologies Used

- **HTML5** — Page structure and forms
- **CSS3** — Styling, layout, and responsive design
- **JavaScript (ES6+)** — Application logic and CRUD operations
- **DOM Manipulation** — Dynamically updating the interface
- **Git & GitHub** — Version control
